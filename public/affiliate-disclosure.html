Affiliate Disclosure

As an Amazon Associate, NeatClock earns from qualifying purchases.

Where affiliate links appear

NeatClock does not show ads or affiliate links on this website. Instead, when you export a .ics calendar file with a task that matches one of a short list of common household or vehicle chores (for example, an HVAC filter replacement or an engine oil change), the exported calendar event's description may include a short tip and an Amazon search link tagged with our Associates ID.

That link travels with the calendar event into whatever app you import it into (Google Calendar, Apple Calendar, Outlook, etc.) — far away from this page. Because of that, every link we generate is labeled inline as (affiliate link) directly next to the URL, so the disclosure travels with the link itself rather than only living on this page.

What this means for you

If you click one of these links and buy something on Amazon, NeatClock may earn a small commission at no extra cost to you. We only attach these hints to a small, fixed set of task names — see src/config/affiliateHints.js in the source code for the exact list. You can turn this off entirely for your own export by simply not using those task names, or by removing the task before exporting.

Turning it off

NeatClock is a generator, not a subscription — there's nothing to opt out of beyond editing your task list before you export. No tracking pixel, cookie, or account is tied to whether you click an affiliate link.
