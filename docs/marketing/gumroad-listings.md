## Gumroad Setup Tips

### Product Images
- Use a mockup of the print pack (checklist on a fridge, garage wall, or desk)
- Canva has free "product mockup" templates — upload your PDF preview and export as PNG
- Gumroad recommends 1200×1200px or 1200×630px (landscape)

### Product Tags (Optional)
```
productivity, calendar, maintenance, checklist, printable, PDF, home, car, freelance, taxes
```

### Content Ratings
- Select: **Everyone** (G-rated content)

### File Uploads
Each product should include:
- `neatclock-[home|car|cfo]-poster.pdf` (full-page A4/Letter layout)
- `neatclock-[home|car|cfo]-compact.pdf` (fridge magnet / glove box / desk mat size)

For the bundle, upload all six PDFs as one product.
